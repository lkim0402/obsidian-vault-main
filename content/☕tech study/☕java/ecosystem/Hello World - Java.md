>Java is an object oriented language, so every function is a method
```java
public class HelloWorld // class
{ 
    public static void main(String[] args) // method
    {
        System.out.println("Hello World");
    }
}
```
- `System.out.println`
	- Class System, out variable, println function
- `println` vs `print`
	- `println` gives you newline
