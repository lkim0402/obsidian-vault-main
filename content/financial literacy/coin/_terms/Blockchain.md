> [!Definition] 
> >An ongoing constantly re-verified record of every single transaction ever made using that currency.
> >공개적으로 많은 사람이 동시에 작성하는 거래 장부. 많은 사람이 같은 거래 내역을 분산해 기록하고, 기록하는 과정에서 내용이 올바른지 검증하는 과정을 거침
> >- 위조가 불가능함

- Almost all [[Cryptocurrency]] are powered by this
- It's a list of transactions anyone can view and verify
- Divided into blocks (segments)
	- Connected through a secure encryption algorithm
	- Each contains transaction data
	- Stored chronologically
- Used outside of [[Cryptocurrency]]: healthcare records, streamline supply chains, and more
- Public blockchain
	- 공개된 블록체인
	- 비트코인, 이더리움이 해당
- Private blockchain
	- 특정 조직이나 그룹 내에서만 사용됨.
	- 참여자가 제한되어 있고 외부에 공개되지 않으며 보다 통제된 환경에서 운영됨

### Process
- 비트코인 네트워크에서 **블록체인의 장부를 업데이트**하고 **거래를 검증**하는 작업을 수행하는 **노드 운영자**(주로 채굴자)에게 **비트코인**으로 보상이 지급됨
	- 이 보상은 **블록 보상**이라고 불리며, 비트코인 네트워크의 유지와 운영에 필요한 비용을 커버하는 중요한 역할을 합니다
- 장부를 업데이트하려면 채굴자들은 **엄청난 컴퓨터 연산**을 해야함 -> 연산을 푼 채굴자가 새로운 **블록**을 만들고, 보상으로 블록체인의 코인을 얻게 됨 -> 나머지 노드들은 이 블록을 검증하고 장부에 추가
- 노드들도 문제를 풀고 있지만, 블록을 추가할 수 있는 건 **첫 번째로 문제를 푼 노드**뿐

### Node vs miner
**모든 채굴자는 노드이지만, 모든 노드는 채굴자가 아님.**
- **노드**
	- 비트코인 네트워크에 연결된 모든 컴퓨터
	- 이들은 **거래를 검증하고, 블록체인을 유지**함
- **채굴자(Miner)**
	- **수학 문제를 풀어 새로운 블록을 생성**하고 그에 대한 **비트코인 보상**을 받는 특별한 노드
